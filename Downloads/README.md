Die aktuelle Arbeitsmappe ist **StatBoardReakt_2026_Dashboard_v3_geschuetzt.xlsm**.

In GitHub die Datei öffnen und **Download raw file** wählen. Das Öffnungskennwort wurde separat im privaten Chat mitgeteilt und steht nicht im Repository.

Die Arbeitsmappe im Jahresordner 2026 neben StatReaktImport.csv speichern. Die aktuellen CSV-Daten lassen sich in Excel Desktop über **Daten > Alle aktualisieren** einlesen. Die neuen Ansichten teilen ihre Filter im Blatt **Trends & Vergleich**. Jedes neue Dashboard ist auf eine DIN-A4-Hochformatseite eingerichtet.

Die optionalen [Hilfsdateien für das Jahresarchiv](Jahresarchiv/Jahresarchiv_Bedienung.md) ermöglichen lokale Vergleiche abgeschlossener Jahresquellen. Es sind zunächst keine historischen Daten geladen. Die Archivverbindung ist bis zur Einrichtung deaktiviert.

Für eine neue Jahresdatei die CSV-Verbindung auf den neuen Jahresordner einstellen, **CSV-Quelljahr** im Blatt **Anleitung** anpassen und das gewünschte Auswertungsjahr im Jahresblick wählen. Das Quelljahr bleibt unabhängig vom Vidierungsjahr und vom Auswertungsfilter.

Im Repository befindet sich ausschließlich die verschlüsselte Arbeitsmappe mit allgemeinen Hilfsdateien. Rohdaten und erzeugte Archiv-CSV gehören auf das private Abteilungslaufwerk.
